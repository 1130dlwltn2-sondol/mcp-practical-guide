# MCP 실전 가이드

Model Context Protocol을 처음부터 끝까지 다룬 실전서입니다.

MCP는 AI 모델이 외부 도구와 데이터에 연결되는 방식을 통일한 공개 표준입니다. 2024년 11월 Anthropic이 공개한 뒤, 2026년 현재 OpenAI, Google, Microsoft, AWS가 모두 채택했고, Linux Foundation 산하 Agentic AI Foundation으로 이관되어 벤더 중립 표준으로 자리 잡았습니다. 이 책은 프로토콜 개요와 아키텍처부터 Python과 TypeScript SDK 실습, MCP Inspector 활용, Claude Code와 Claude Desktop, VS Code, Cursor 연동, 원격 MCP 서버 구축과 OAuth 인증, Elicitation, 운영과 보안까지 다룹니다.

책의 마지막에는 사내 API를 감싸는 팀용 원격 MCP 서버를 구축하고 OAuth로 보호해 Claude Code와 연동하는 실전 프로젝트와 확인 문제 20문항, 상세 해설을 수록했습니다.

- 대상 독자: MCP를 처음 접하는 개발자부터, 팀에 MCP를 도입하려는 엔지니어까지
- 기준일: 2026-10-09 (MCP 스펙은 계속 발전하니 공식 문서를 함께 확인하세요)
- 구성: 첫 페이지, 책 소개, 전체 목차, Part 1~7 본문 20개 장, 실전 프로젝트, 확인 문제, 마무리
- 저장소: https://github.com/1130dlwltn2-sondol/mcp-practical-guide
