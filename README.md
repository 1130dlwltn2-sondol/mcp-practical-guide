# MCP 실전 가이드

MCP를 처음 접하는 개발자부터 팀에 도입하려는 엔지니어까지, AI 도구마다 따로 만들던 외부 도구·데이터 연결을 공개 표준 하나로 정리하고 직접 서버를 만드는 실전서입니다.

## 누구를 위한 책인가요?
- 대상 독자: MCP 입문 개발자, 사내 API를 AI 도구에 연결하려는 엔지니어
- 수준: 입문 → SDK 실습 → 클라이언트 연동 → 원격 서버 운영·보안 → 실전 프로젝트

## 무엇을 배우고 만드나요?
- MCP 개요와 Host·Client·Server 구조, 전송 방식, 세 가지 프리미티브를 이해합니다.
- Python·TypeScript SDK로 MCP 서버를 만들고 Inspector로 테스트합니다.
- Claude Desktop·Claude Code·VS Code·Cursor에 연결하고 OAuth 인증, Elicitation, 운영·보안을 익힙니다.
- 결과물: 사내 문서 검색 API를 도구로 제공하고, OAuth와 사용자별 권한으로 보호하며 Claude Code에서 공유하는 팀용 원격 MCP 서버

## 실전 프로젝트
사내 API를 감싸는 팀용 원격 MCP 서버를 구축합니다. 문서 검색 도구를 만들고 Streamable HTTP 서버로 실행한 뒤, Inspector 테스트·컨테이너 구성·OAuth 인증·HTTPS 배포·모니터링·Claude Code 연동까지 이어갑니다.
