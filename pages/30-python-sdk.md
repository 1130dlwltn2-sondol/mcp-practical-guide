# Part 3. MCP 서버 만들기

## 30. Python SDK 실습

이제 직접 MCP 서버를 만듭니다. Python SDK가 가장 진입 장벽이 낮습니다.

먼저 SDK를 설치합니다. pip install mcp 명령으로 설치됩니다. 가상환경을 쓰는 것이 좋습니다.

가장 단순한 서버는 도구 하나를 제공하는 것입니다. 예를 들어 두 수를 더하는 도구를 만듭니다. 서버 객체를 만들고, 도구로 등록할 함수에 데코레이터를 붙입니다. 함수의 이름이 도구 이름이 되고, 독스트링이 도구의 설명이 됩니다. 입력값의 타입 힌트가 입력 형식으로 쓰입니다. 타입 힌트를 정확히 쓰는 것이 중요합니다. AI가 이 정보를 보고 도구를 쓰기 때문입니다.

서버를 실행하면 stdio로 대기합니다. 이 상태에서는 직접 테스트하기 어려우니, 다음 장의 Inspector를 씁니다. 또는 간단한 클라이언트 스크립트로 tools/list를 호출해 도구가 등록됐는지 확인합니다.

도구를 설계할 때의 요령입니다. 하나의 도구는 하나의 일을 합니다. 이름은 동사로 시작하고 명확하게 짓습니다. 설명에는 언제 쓰는지, 입력값의 형식을 적습니다. 예를 들어 "지정한 도시의 현재 날씨를 조회합니다. 도시명은 영문으로 입력합니다." 같은 식입니다. 에러가 나면 이해하기 쉬운 메시지를 돌려줍니다. AI가 에러 메시지를 보고 대처하기 때문입니다.

실습: 계산기 서버
1. mcp 패키지 설치하기
2. 더하기, 빼기 도구를 제공하는 서버 작성하기
3. Inspector로 도구 목록 확인하기

핵심 정리
- pip install mcp로 SDK를 설치한다.
- 함수에 데코레이터를 붙이면 도구가 된다.
- 이름, 설명, 타입 힌트가 도구의 사용 설명서다.
