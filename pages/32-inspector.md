# 32. MCP Inspector

MCP Inspector는 서버를 테스트하는 공식 도구입니다. 클라이언트를 연결하기 전에 서버가 제대로 동작하는지 확인합니다.

실행은 npx @modelcontextprotocol/inspector 명령으로 합니다. 브라우저에 테스트 화면이 열립니다. 서버 실행 명령을 입력하면 연결됩니다. stdio 서버는 실행 명령을, HTTP 서버는 URL을 넣습니다.

화면에서는 도구 목록을 보고, 직접 실행해 볼 수 있습니다. 입력값을 넣고 실행하면 결과가 표시됩니다. 리소스와 프롬프트도 같은 방식으로 확인합니다. 알림이 오는지도 볼 수 있습니다.

Inspector를 쓰는 습관이 디버깅 시간을 줄입니다. 클라이언트에 연결했는데 동작이 이상하면, 먼저 Inspector로 서버 단독 동작을 확인합니다. 서버가 정상이면 클라이언트 설정 문제이고, 서버도 이상하면 서버 코드 문제입니다. 문제를 좁히는 순서입니다.

자주 확인하는 항목입니다. 도구 목록이 뜨는지, 설명이 의도대로 표시되는지, 입력 형식이 맞는지, 실행 결과가 예상대로 오는지, 에러 메시지가 이해하기 쉬운지입니다. 이 다섯 가지만 봐도 대부분의 문제를 잡습니다.

실습: Inspector로 테스트
1. 앞에서 만든 계산기 서버를 Inspector에 연결하기
2. 도구 목록과 실행 결과 확인하기
3. 잘못된 입력으로 에러 메시지 확인하기

핵심 정리
- Inspector는 클라이언트 연결 전 서버를 테스트하는 도구다.
- 도구 목록, 실행, 에러 메시지를 확인한다.
- 문제가 생기면 서버 단독 동작부터 확인한다.
