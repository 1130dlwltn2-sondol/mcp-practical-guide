# 42. VS Code와 Cursor

VS Code와 Cursor도 MCP를 지원합니다. 한 번 만든 서버를 에디터에서도 그대로 씁니다.

VS Code는 설정 파일에 MCP 서버를 등록합니다. Copilot이 MCP를 지원하므로, 설정에 서버를 추가하면 코드 작업 중에 도구를 씁니다. 예를 들어 "이 함수의 테스트를 DB 스키마에 맞게 작성해줘"라고 하면, MCP 서버에서 스키마를 가져와 씁니다.

Cursor는 설정 화면에서 MCP 서버를 추가합니다. 서버를 등록하면 Composer가 필요할 때 도구를 호출합니다. 코드베이스와 외부 데이터를 함께 쓰는 작업에 유용합니다.

에디터에서 MCP를 쓸 때의 장점은 문맥입니다. 보고 있는 파일, 선택한 코드가 자동으로 컨텍스트가 됩니다. MCP 서버의 도구와 합쳐지면 "선택한 코드의 관련 문서를 찾아줘" 같은 작업이 자연스러워집니다.

여러 클라이언트에 같은 서버를 연결할 때는 설정을 각자 해야 합니다. 설정 형식은 클라이언트마다 조금씩 다릅니다. 공식 문서의 클라이언트별 예제를 참고하세요. 서버 자체는 하나이니, 서버 코드는 고칠 필요가 없습니다. 이것이 MCP의 장점입니다.

핵심 정리
- VS Code와 Cursor도 MCP 서버를 그대로 쓴다.
- 에디터의 문맥과 MCP 도구가 합쳐지면 강력하다.
- 서버는 하나, 설정만 클라이언트별로 한다.
