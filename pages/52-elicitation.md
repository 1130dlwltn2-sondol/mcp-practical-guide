# 52. Elicitation

Elicitation은 서버가 사용자에게 추가 정보를 요청하는 기능입니다. 클라이언트가 제공하는 프리미티브입니다.

예를 들어 보겠습니다. 서버에 "보고서 생성" 도구가 있습니다. 실행하려면 기간과 형식이 필요합니다. AI가 기간을 모르면, 서버가 Elicitation으로 사용자에게 "어느 기간의 보고서인가요?"라고 묻습니다. 사용자가 답하면 서버가 이어서 처리합니다.

동작 방식은 왕복 요청입니다. 서버가 elicitation/create를 보내면, 클라이언트가 사용자에게 보여주고 답을 받아 돌려줍니다. AI가 중간에 끼지 않고 사용자와 직접 묻고 답합니다. 확인이 필요한 작업에도 씁니다. "정말 삭제할까요?" 같은 확인을 Elicitation으로 받을 수 있습니다.

언제 쓰는지 정리합니다. 도구 실행에 필수 정보가 빠졌을 때 씁니다. 사용자의 확인이 필요할 때 씁니다. AI가 지어내면 안 되는 정보를 받을 때 씁니다. 반대로 남용하면 사용자가 피로해집니다. 꼭 필요할 때만 묻습니다.

참고로 예전에는 Sampling이라는 기능이 있었지만, 2026년 7월 스펙부터 deprecated 되었습니다. 새로 만든다면 Elicitation을 쓰고, Sampling은 쓰지 마세요.

실습: 확인 요청
1. 삭제 도구에 Elicitation 확인을 붙이기
2. Inspector에서 실행해 보기
3. 사용자 응답에 따라 동작이 달라지는지 확인하기

핵심 정리
- Elicitation은 서버가 사용자에게 직접 묻는 기능이다.
- 필수 정보 수집과 확인에 쓴다.
- 꼭 필요할 때만 물어 사용자 피로를 줄인다.
