# 80. 확인 문제와 해설

20문제로 배운 내용을 점검합니다.

1. MCP의 세 참여자는?
2. Host의 역할은?
3. Client는 언제 만들어지는가?
4. Server가 꼭 네트워크 너머에 있어야 하는가?
5. 데이터 계층과 전송 계층의 차이는?
6. discovery란 무엇인가?
7. 상태 비저장이란 무슨 뜻인가?
8. Stdio와 Streamable HTTP는 각각 언제 쓰는가?
9. 세 가지 프리미티브를 쓰시오.
10. Tools와 Resources의 구분 기준은?
11. Prompts의 용도는?
12. Python SDK에서 함수가 도구가 되는 방법은?
13. 도구 설명을 잘 쓰는 요령은?
14. Inspector의 용도는?
15. Claude Desktop에 서버를 등록하는 방법은?
16. 원격 서버의 권장 인증 방식은?
17. Elicitation이란 무엇인가?
18. Sampling의 현재 상태는?
19. 로그에 비밀값을 남기면 안 되는 이유는?
20. 도구 입력 형식을 바꾸는 것은 어떤 변경인가?

해설

1. MCP Host, MCP Client, MCP Server.
2. 사용자가 직접 쓰는 AI 애플리케이션으로, 여러 클라이언트를 관리한다.
3. Host가 서버에 연결할 때, 서버별로 하나씩 만들어진다.
4. 아니다. 로컬 프로세스로 도는 것도 MCP 서버다.
5. 데이터 계층은 주고받는 내용, 전송 계층은 주고받는 방법이다.
6. 클라이언트가 서버의 버전과 기능을 먼저 파악하는 과정이다.
7. 각 요청이 독립적으로 처리되고, 서버가 이전 요청을 기억하지 않는 것이다.
8. Stdio는 로컬용, Streamable HTTP는 원격용이다.
9. Tools, Resources, Prompts.
10. 상태를 바꾸면 Tools, 읽기만 하면 Resources다.
11. 자주 쓰는 지시문을 재사용 가능한 템플릿으로 만드는 것이다.
12. 함수에 데코레이터를 붙인다. 이름, 독스트링, 타입 힌트가 도구의 설명이 된다.
13. 이름은 명확하게, 설명에는 언제 쓰고 입력값 형식을 적는다.
14. 클라이언트 연결 전 서버를 단독으로 테스트하는 공식 도구다.
15. 설정 파일의 mcpServers에 등록하고 다시 시작한다.
16. OAuth다.
17. 서버가 사용자에게 추가 정보나 확인을 직접 요청하는 기능이다.
18. 2026년 7월 스펙부터 deprecated 되었다.
19. 로그가 유출되면 비밀이 그대로 노출되기 때문이다.
20. 호환성이 깨지는 변경이다. 새 버전을 추가하고 점진적으로 전환한다.
